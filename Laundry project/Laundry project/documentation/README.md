# LaundryPro static HTML template

## Quick start

Open `index.html` in a modern browser. No build process or backend is required.

## Customisation

- Brand tokens live at the top of `assets/css/style.css`.
- Shared JavaScript behaviour is in `assets/js/main.js`.
- Update contact information and demo imagery before production.
- Bootstrap, Font Awesome, AOS and GLightbox are loaded from CDN; download them to `assets/vendors/` for a fully offline package.

## Included

Two homes, service/pricing/booking flows, blog and gallery, FAQ/contact, auth states, utility pages, light/dark toggle, responsive grid and validated demo forms. RTL is supported by adding `dir="rtl"` to the HTML element and Bootstrap RTL stylesheet in production.
